# Распределение темпа по сплитам

## Входные данные

Список значений темпа в секундах на км (например `[429, 512, 535, ...]`).

---

## Размер бакета

Используй правило Стёрджеса:

```
k = round(1 + 3.322 * log10(n))
bucket_size = (max - min) / k
```

Округли `bucket_size` до ближайшего кратного 30 секундам сверху (30, 60, 90, 120).

Примеры:
- 14 сплитов → k=5, raw=109 сек → **120 сек** (2 мин)
- 30 сплитов → k=6 → скорее всего **60 сек** (1 мин)
- 8 сплитов → k=4 → **90 сек**

Минимальный размер бакета — 30 сек, максимальный — 120 сек.

---

## Средний темп

```
mean = sum(all_paces) / n
```

Простое среднее, взвешивание по времени не нужно.

---

## Медианный темп

Сортируй значения по возрастанию:

```
если n нечётное → median = sorted[n // 2]
если n чётное   → median = (sorted[n // 2 - 1] + sorted[n // 2]) / 2
```

---

## Границы цветов

Используй стандартное отклонение:

```
std = sqrt(sum((x - mean)^2) / n)
```

| Цвет | Условие | Смысл |
|------|---------|-------|
| Зелёный | `pace < mean - 0.75 * std` | Быстро |
| Синий | между границами | Норма |
| Красный | `pace > mean + 0.75 * std` | Медленно |

Коэффициент 0.75 даёт ~25% значений зелёными, ~25% красными, ~50% синими.
Можно менять: 0.5 — жёстче, 1.0 — мягче.

---

## Итоговый алгоритм

```python
import math, statistics

paces = [...]  # секунды/км

n = len(paces)
mean = sum(paces) / n
median = statistics.median(paces)
std = statistics.stdev(paces)

k = round(1 + 3.322 * math.log10(n))
raw_bucket = (max(paces) - min(paces)) / k
bucket_size = math.ceil(raw_bucket / 30) * 30  # округление до 30 сек

green_threshold = mean - 0.75 * std   # быстрее → зелёный
red_threshold   = mean + 0.75 * std   # медленнее → красный
```
